Junando — AWS Serverless Architecture

Alertmanager → SQS-buffered Lambda pipeline → LLM analysis → Slack/Teams. Service icons are the official AWS Architecture Icons, drawn from draw.io's built-in AWS4 shape library.

Pipeline

  • Alertmanager posts to a public webhook Function URL
  • Alerts fan out via an SQS FIFO queue to the worker
  • The worker correlates, dedups, and calls the LLM provider

State & secrets

  • DynamoDB backs fingerprint+TTL dedup by default (Redis is a supported alternative)
  • SSM Parameter Store holds every provider credential — read at cold start
  • The DLQ catches messages that exhaust SQS maxReceiveCount

External boundaries

  • LLM provider is pluggable — Gemini, Claude, OpenRouter, Qwen, or Bedrock
  • Notifications go to Slack or Teams, never both at once
  • A separate monitoring account scrapes /metrics over an IAM-signed Function URL
